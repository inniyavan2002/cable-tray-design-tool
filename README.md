# Cable Tray Design Tool

A browser-based electrical engineering tool developed for **cable tray sizing, cable selection, design calculations, section visualization, and project documentation**.

## 🔧 Tool Overview

The Cable Tray Design Tool helps electrical engineers and MEP designers simplify the cable tray design process by bringing important design activities into one workspace.

### Key Features

* Cable selection and sizing
* Cable tray width and height calculation
* Multi-tray arrangement
* Cable grouping and arrangement
* Tray fill calculation
* Design calculation summary
* Cable cross-section visualization
* Manufacturer/product selection
* Professional project documentation
* Calculation review
* Export-ready project information

## ⚡ Design Workflow

The tool supports a practical workflow:

**Cable Details → Cable Selection → Tray Sizing → Calculation → Section View → Documentation**

This helps reduce repetitive manual calculations and improves consistency during electrical design.

## 📐 Cable Tray Design

The tool can be used to review:

* Number of cables
* Cable sizes
* Cable arrangement
* Cable dimensions
* Tray width
* Tray height
* Cable occupancy/fill
* Available tray space
* Design summary

## 📊 Calculation Review

The calculation section provides a clear summary of the design inputs and calculated results so that the engineer can review the tray selection before using the information in project documentation.

## 👁️ Section Visualization

The section view provides a visual representation of the cables inside the selected tray.

This helps the designer understand:

* Cable arrangement
* Available space
* Tray utilization
* Cable positioning
* Overall tray configuration

## 🏭 Manufacturer Support

The tool is designed to support cable tray selection from commonly used manufacturer/product catalogues.

Manufacturer information can be reviewed alongside the design requirements to assist with product selection.

## 📄 Documentation

The tool is intended to support professional electrical/MEP project documentation by providing organized design information and calculation results.
