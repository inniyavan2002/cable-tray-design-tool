# Cable Tray Design Software

Browser-based cable tray sizing and documentation workspace.

## Run locally

Open `index.html` in a modern browser. Use **Open Design Tool** to launch `tool.html`.

Keep the `pdfs/` folder beside `tool.html` so the manufacturer source-page viewer can load the catalogues.

## GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save. GitHub Pages will publish `index.html` as the landing page.

## Package

- `index.html` — release landing page
- `tool.html` — cable tray design application
- `Cable_Tray_Design_Software_User_Readme.docx` — detailed user guide
- `pdfs/` — manufacturer catalogue PDFs
- `poster-preview.png` — release poster/preview
